01 / Capabilities

Everything a banking
API should be.

💳

Card Management

Create, view, block, and delete bank cards. Card numbers are AES-128 encrypted — only masked values are ever returned.

🔄

Atomic Transfers

Transfer funds between cards with full overdraft protection, balance checks, and card status validation — all in a single transaction.

🔐

JWT Auth

Stateless 24-hour tokens. Role-based access control separates USER and ADMIN capabilities at every layer.

🛠️

Admin Controls

Full admin surface for managing users, toggling card status, and auditing all accounts across the platform.

02 / Endpoints

Clean, predictable
REST design.

MethodPathDescription
POST /api/v1/auth/login Authenticate and receive a JWT token
POST /api/v1/auth/register Register a new user account
GET /api/v1/cards List your cards — filterable, paginated
POST /api/v1/transfers Transfer funds between your cards
PATCH /api/v1/admin/cards/{id}/status Set card status ADMIN
GET /api/v1/admin/users List all users ADMIN
DELETE /api/v1/admin/cards/{id} Delete a card permanently ADMIN

Full interactive docs at /swagger-ui.html
