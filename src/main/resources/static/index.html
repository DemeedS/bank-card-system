Bank Card Management
at Your Fingertips

A secure, JWT-authenticated REST API for managing bank cards, processing transfers, and administering accounts — built with Spring Boot and PostgreSQL.

API Online 🔐 JWT Authentication 🛡️ AES-128 Card Encryption 🗄️ PostgreSQL · Neon 🚀 Deployed on Render

Core Capabilities

💳

Card Management

Create, view, block, and delete bank cards. Card numbers are AES-128 encrypted at rest — only masked values are ever returned.

🔄

Secure Transfers

Atomically transfer funds between cards with overdraft protection, balance validation, and card status checks.

🔐

JWT Auth

Stateless authentication with 24-hour tokens. Role-based access control separates USER and ADMIN capabilities cleanly.

🛠️

Admin Controls

Admin-only endpoints for managing users, blocking cards, and viewing all accounts across the platform.

Key Endpoints

MethodPathDescription
POST /api/v1/auth/login Authenticate and receive a JWT token
POST /api/v1/auth/register Register a new user account
GET /api/v1/cards List your cards (paginated)
POST /api/v1/transfers Transfer funds between cards
PATCH /api/v1/admin/cards/{id}/status Block or activate a card ADMIN
GET /api/v1/admin/users List all users ADMIN
DELETE /api/v1/admin/cards/{id} Permanently delete a card ADMIN

Full interactive documentation available at /swagger-ui.html
