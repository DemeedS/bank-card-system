Core Capabilities
💳

Card Management

Create, view, block, and delete bank cards. Card numbers are AES-encrypted at rest — only masked values are ever returned.

🔄

Secure Transfers

Atomically transfer funds between cards with full balance validation, overdraft protection, and status checks.

🔐

JWT Auth

Stateless authentication with 24-hour tokens. Role-based access control separates USER and ADMIN capabilities.

🛠️

Admin Controls

Admin-only endpoints for managing users, blocking cards, and viewing all accounts across the platform.

Key Endpoints
POST /api/v1/auth/login Authenticate and get a JWT token
POST /api/v1/auth/register Register a new user account
GET /api/v1/cards List your cards (paginated)
POST /api/v1/transfers Transfer funds between cards
PATCH /api/v1/admin/cards/{id}/status Block or activate a card (ADMIN)
GET /api/v1/admin/users List all users (ADMIN)
DELETE /api/v1/admin/cards/{id} Permanently delete a card (ADMIN)
